# Tic Tac Toe Solved Game AI

This Python script demonstrates a Tic-Tac-Toe game where the computer plays using the Minimax algorithm. It showcases how a simple game can be 'solved' by pre-calculating optimal moves for all possible game states.

## Language

`python`

## How to Run

Save the code as `tic_tac_toe_ai.py` and run it from your terminal using `python tic_tac_toe_ai.py`.
